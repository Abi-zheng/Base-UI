组件库

    Combobox 组合输入框

    用于移动端“可输入 + 可选择”的统一输入体验。输入框是唯一主控件，候选 bottom sheet 以非模态方式辅助输入。

    交互 Demo

    预览终端

    ⌄

    支持自由输入；候选项仅用于快速填充，不强制选择。

    组件状态

    Empty

    默认态，输入为空，不展示候选面板。

    Focused / SuggestionsVisible

    输入框聚焦后弹出键盘，并展示 bottom sheet 候选列表。

    Typing / Filtering

    用户输入时实时过滤历史、常用和推荐候选项。

    NoMatch

    无匹配结果时展示“使用当前输入”，允许自定义提交。

    Selected / CustomValue

    点击候选项或直接提交当前输入，两者最终都写入同一个 value。

    建议 API

    属性 类型 说明
    value string 输入框当前值，也是最终提交值。
    options OptionGroup[] 候选数据，可按历史、常用、推荐分组。
    allowCustomValue boolean 是否允许无匹配时使用当前输入，默认建议为 true。
    onChange function 输入变化时触发。
    onSelect function 点击候选项时触发。
    onSubmit function 提交时返回 value 与来源：option 或 custom。
